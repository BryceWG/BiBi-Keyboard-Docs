# 键盘布局与按钮

本页介绍主键盘面板上的各个按钮、自定义键盘布局编辑器、AI 编辑面板以及数字/符号键盘的用法。

::: tip 长按提示
主键盘按钮与 AI 编辑面板按钮支持长按查看提示。如果一时不确定某个图标的作用，可以先长按确认，再决定是否点击。
:::

## 主键盘默认功能布局

### 顶部功能行

- **AI 编辑（铅笔图标）**：从主键盘进入 AI 编辑面板。需要已配置语音识别和 LLM；否则会在键盘状态栏提示需要配置密钥。
- **AI 后处理开关（魔法棒图标）**：切换是否在每次语音识别完成后自动调用 AI 后处理，具体行为见 [AI 后处理](./ai-postprocess.md)。
- **剪贴板（剪贴板图标）**：打开内置剪贴板面板，浏览并插入最近复制的内容。列表中右滑可固定/取消固定，左滑可删除；已固定记录需先右滑取消固定。
- **退格**：删除光标前一个字符，支持长按连续删除和滑动手势（详见 [手势操作](./gestures.md)）。

### 中间功能行（覆盖行）

- **设置（齿轮图标）**：打开「说点啥」设置界面。
- **Prompt 选择（文章图标）**：弹出已配置的 Prompt 列表，切换当前使用的后处理 Prompt。
- **切换输入法（键盘图标）**：打开系统输入法选择器；若开启「输入法切换键可返回指定输入法」，则直接返回 `设置 → 输入 → 输入设置 → 输入行为 → 指定输入法` 中选定的输入法（未指定时返回上一个输入法）。
- **回车**：根据当前输入框类型发送换行或提交动作。

### 标点与空格行

- **数字/符号键盘入口**：最左侧「数字键盘」图标，点击后显示数字/符号键盘。
- **合并标点键 A/B**：中间两枚标点键：
  - 点击：输入配置中的第 1/3 个常用标点；
  - 上滑：输入第 2/4 个常用标点。
  默认标点可在 `设置 → 系统 → 其他设置 → 自定义标点按钮` 中修改。
- **供应商切换**：最右侧圆点图标，点击在已配置的 ASR 供应商之间快速切换。
- **空格键**：中间长条按钮，正常情况下输入空格；在录音长按模式下，按住麦克风并向下滑到空格区可以锁定录音，再次点击空格结束录音。

## 自定义键盘布局编辑器

整个键盘由布局编辑器驱动的网格块组成。可以把常用按钮放到顺手的位置、调整块尺寸，或隐藏不常用的功能。

### 配置入口

路径：`设置 → 输入 → 界面设置 → 键盘界面 → 自定义键盘布局`

1. 在编辑器顶部选择要编辑的面板
2. 在画布中点击要修改的按钮块
3. 从动作列表中选择新功能，或调整块尺寸
4. 保存后回到键盘查看效果

编辑器能力：

- **三个面板分别编辑**：主键盘、AI 编辑、录音（录音面板包含「左滑取消」「右滑发送」两个手势块）
- **行列数可调**：默认 7 列 × 4 行
- **块尺寸调整**：多数块支持多种尺寸组合
- **恢复默认**：布局不顺手时可一键重置
- **JSON 导入/导出**：复制布局 JSON 即可分享给别人，也可导入他人分享的布局

::: tip 建议
初次调整时建议只改少量按钮，熟悉编辑器逻辑后再做整体定制。
:::

### 可配置动作

**扩展动作**（默认布局在键盘顶部两侧放置「撤销、全选、复制、收起键盘」；除面板固定块外可自由添加，同一布局内每个动作最多一个实例）：

| 动作 | 说明 |
| ---- | ---- |
| 撤销 | 撤销最近一次文本修改（包括语音识别提交、AI 后处理、手动输入等） |
| 全选 | 选中当前输入框全部文字 |
| 复制 | 将当前选中文本复制到剪贴板 |
| 粘贴 | 在光标处粘贴剪贴板内容（带撤销） |
| 选择模式 | 进入/退出选择模式，配合光标移动键精细选中一段文本 |
| 识别历史 | 在键盘内打开识别历史面板，点击条目插入文本；右滑重新润色、左滑重新识别（详见 [语音输入基础](./voice-input.md#键盘内的识别历史)） |
| 剪贴板 | 打开剪贴板面板，浏览并插入最近复制的内容 |
| 收起键盘 | 收起当前键盘面板 |
| 录音判停 | 快速开启/关闭「停说自动停止录音」 |
| 录音模式切换 | 在长按说话和点按启停之间快速切换 |
| 悬浮键盘 | 切换悬浮键盘窗口 |
| 输入完成后自动回车 | 切换自动发送开关；开启后每次识别（及可选 AI 后处理）完成都会自动回车或触发编辑器发送动作。也可在 `设置 → 输入 → 输入设置 → 输入行为 → 输入完成后自动回车` 中开启；如只想临时发送一次，可保持关闭，并在录音时右滑麦克风 |
| 左移 / 右移 | 每次移动一个字符，长按可连续移动 |
| 上个标点 / 下个标点 | 将光标移动到上一个/下一个断句标点处 |
| 移至开头 / 移至结尾 | 将光标移动到文本最前或最后 |
| 数字键盘 | 打开数字/符号键盘 |

**面板固定块**（可在编辑器中移动、调整尺寸）：

| 面板 | 固定块 |
| ---- | ------ |
| 主键盘 | 麦克风、状态栏、AI编辑、AI润色、剪贴板、退格、设置、切换润色 Prompt、切换输入法、回车、数字小键盘、两枚标点键（编辑器中显示为「自定义按键 2/3」）、空格、切换 ASR 供应商 |
| AI 编辑 | AI 信息栏、麦克风、返回主键盘、应用预设 Prompt、全选、退格、光标左移/右移、复制、粘贴、数字小键盘、切换选择模式、空格、移到开头/末尾 |
| 录音 | 左滑取消、右滑发送 |

当某个按钮被配置为「选择模式」或「录音判停」时，其图标会随着当前状态高亮或变暗，方便确认是否已开启。

## 输入法切换小技巧

### 快捷设置磁贴

您可以把「切换输入法」加入 Android 系统快捷设置（QS）面板：

1. 下拉系统快捷设置面板
2. 点击编辑（铅笔图标）
3. 找到「切换输入法」并拖入面板

之后点一下磁贴即可弹出系统输入法选择器。

### 触觉反馈强度

如果觉得按钮震动偏强或偏弱，可在 `设置 → 输入 → 界面设置 → 键盘界面 → 输入/点击振动反馈强度` 中调整。

## AI 编辑面板

AI 编辑面板用于对现有文本进行「二次加工」，例如润色、翻译或按指令编辑。

### 打开方式

1. 在主键盘顶部点击 **AI 编辑**（铅笔图标）；  
2. 若尚未配置 ASR 或 LLM 密钥，会在状态栏提示，需要先在设置中完成配置。

### 基本流程

1. 在应用中选中要编辑的文本；若没有选区，则默认编辑整个输入框内容（可在 `设置 → 智能 → AI 功能设置` 中改为优先使用「上次识别结果」）。若只想修改局部内容，请先选中再开始录音。
2. 点击键盘上的麦克风按钮，说出编辑指令（例如“翻译成英文并简化句子”）。
3. 说完后再次点击麦克风或松开（取决于录音模式），等待识别与 AI 处理完成。
4. 处理结果会自动替换选中文本或整段文本，可通过撤销功能恢复。

为避免误改到非目标内容，开始录音后建议不要再调整选区或移动光标；如果误触导致替换范围不符合预期，可先撤销，再重新选中后重试。

### 信息栏（顶部提示条）

- **待机时**：显示当前录音模式下的操作引导（点按开始/结束，或长按说话后松开）。
- **录音时**：显示「请说出编辑指令…」或实时识别到的指令文本。
- **处理中**：显示「AI 编辑中…」。
- **异常时**：会临时显示错误提示，便于快速定位问题。

### 面板内按钮

- **返回**：关闭 AI 编辑面板，回到主键盘。
- **应用预设 Prompt**：从 Prompt 预设列表中选择一条，仅对当前一次编辑生效。
- **光标左移 / 右移**：在当前文本中移动光标，长按可连续移动。
- **移至开头 / 结尾**：将光标移动到文本开头或结尾。
- **选择模式**：开关选择模式，配合光标移动选择一段文本。
- **全选**：选中当前输入框全部内容。
- **复制**：复制当前选中文本到剪贴板，并显示预览。
- **粘贴**：在光标处粘贴剪贴板内容（带撤销）。
- **空格键**：插入空格；如果当前正在录音（例如正在说编辑指令），点击空格键不会插入空格。
- **退格键**：行为与主键盘退格键一致，支持单击删除、长按连续删除及滑动清空/撤销。
- **数字键盘**：从 AI 编辑面板进入数字/符号键盘，返回时自动回到 AI 编辑面板。

## 数字与符号键盘

数字/符号键盘用于快速输入数字和常用符号。

### 打开与返回

- 打开：在主键盘点击标点行最左侧的「数字键盘」键，或在 AI 编辑面板点击数字键盘按钮。
- 返回：点击数字键盘底部左侧的返回按钮：
  - 如果是从 AI 编辑面板进入，则返回 AI 编辑；
  - 否则返回主键盘。

### 布局说明

- **数字行**：顶部一行 `0–9`，等宽排列，点击直接输入数字。
- **符号区**：中间两行固定标点：
  - 第一行：中英文常用标点（逗号、句号、问号、感叹号等）。
  - 第二行：括号、斜杠等符号，末尾为退格键。
- **底部栏**：
  - 返回按钮：返回前一个面板。
  - 标点语言切换：在中文标点和英文标点之间切换。
  - 空格键：输入空格。
  - 回车键：发送换行或提交动作。

符号区的中英文样式会根据底部的标点语言切换按钮即时更新。
