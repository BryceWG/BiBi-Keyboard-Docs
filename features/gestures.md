# 手势操作

说点啥键盘面板提供丰富的手势交互，让您更高效地控制输入、编辑和管理文本。

## 退格键手势

退格键支持多种操作模式，从单字符删除到全文清除、撤销操作，一键触达。

### 基本操作

| 手势         | 功能         | 说明                                   |
| ------------ | ------------ | -------------------------------------- |
| **单击**     | 删除一个字符 | 标准退格行为                           |
| **长按**     | 连续删除     | 每 50ms 删除一个字符，持续按住快速清除 |
| **向上滑动** | 清空全文     | 删除编辑器所有内容                     |
| **向左滑动** | 清空全文     | 与向上滑动相同                         |
| **向下滑动** | 撤销操作     | 恢复上一次修改（支持三级）             |

#### 手势冲突避免

为避免误触，设计了以下机制：

1. **长按优先**：按住超过 500ms 才判定为长按删除
2. **滑动距离阈值**：滑动距离必须 > 50dp（约 8mm）
3. **方向明确性**：要求滑动角度在目标范围内
4. **取消机制**：滑动过程中回到原点可取消操作

### 使用技巧

#### 快速清空输入

**场景**：误识别了一大段内容，需要全部删除

**操作**：

```
按住退格键 → 向上滑动 → 松手
```

比连续点击或长按快得多！

#### 快速撤销误操作

**场景**：不小心清空了全文

**操作**：

```
按住退格键 → 向下滑动 → 松手
```

立即恢复！

#### 连续编辑流程

**场景**：语音识别 → AI 后处理 → 不满意 → 撤销 → 重新识别

**操作**：

```
语音输入 → [AI 处理完成] → 退格向下滑撤销 → 再次语音输入
```

## 全局撤销

除了退格键手势，说点啥还提供全局撤销扩展按钮区功能，可撤销任何类型的文本变更。

### 撤销内容类型

| 操作类型      | 可撤销 | 撤销后状态       |
| ------------- | ------ | ---------------- |
| 语音识别提交  | ✅     | 删除识别结果     |
| AI 后处理修改 | ✅     | 恢复原始识别文本 |
| 手动输入文字  | ✅     | 删除输入内容     |
| 删除字符      | ✅     | 恢复被删除内容   |
| 粘贴文本      | ✅     | 删除粘贴内容     |
| AI 编辑操作   | ✅     | 恢复编辑前文本   |
| 清空全文      | ✅     | 恢复清空前内容   |

### 撤销栈机制

说点啥使用栈结构存储撤销历史：

```
[最近] → 操作3 → 操作2 → 操作1 → [最早]
         ↑撤销     ↑撤销     ↑撤销
```

**栈容量**：最多 3 个历史状态

**溢出处理**：新操作推入时，最旧的状态自动丢弃

## 其他手势

### 麦克风按钮手势

#### 长按模式（默认）

- **长按**：开始录音
- **松开**：停止录音
- **向左滑动**：取消录音
- **向右滑动**：直接发送识别结果
- **向下滑动**：临时锁定录音（无需持续按住）

#### 点按模式

- **单击**：开始/停止录音
- **长按**：取消录音
- **向左滑动**：取消录音
- **向右滑动**：直接发送识别结果

::: info 详细说明
参见 [录音模式](./recording-modes.md) 章节
:::

### 悬浮球手势

#### 基本操作

- **点击**：开始录音
- **长按后向屏幕中间拖动**：呼出菜单
- **长按 2s 拖动**：拖动到新位置，松手自动贴边

::: info 详细说明
参见 [悬浮球功能](./floating-ball.md) 章节
