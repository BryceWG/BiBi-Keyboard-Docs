# 录音模式

说点啥键盘提供三种录音模式，满足不同使用习惯和场景需求。您可以根据个人偏好选择最舒适的交互方式。

## 模式概览

| 模式         | 触发方式                     | 适用场景             |
| ------------ | ---------------------------- | -------------------- |
| **长按说话** | 按住麦克风按钮录音，松开停止 | 传统习惯，精确控制   |
| **点按切换** | 点击麦克风按钮开始/停止      | 长文本输入，解放双手 |

## 长按说话模式（默认）

### 使用方法

1. **开始录音**：长按麦克风按钮
2. **持续录音**：保持按住状态
3. **停止录音**：松开手指

### 配置选项

- **配置项**：`micTapToggleEnabled = false`（默认）
- **路径**：`设置 → 语音识别设置 → 麦克风点按控制`（关闭）

### 特点

::: tip 优势

- ✅ 操作直观，符合主流输入法软件习惯
- ✅ 精确控制录音时长
- ✅ 松手即停，响应迅速
  :::

::: warning 局限

- ⚠️ 长时间录音手指容易疲劳
- ⚠️ 需要持续按住，无法做其他操作
  :::

### 手势增强

长按模式支持手势控制：

- **向左滑动**：取消本次录音
- **向右滑动**：直接发送识别结果
- **向下滑动**：临时锁定录音（无需持续按住，长按模式下生效）

## 点按切换模式

### 使用方法

1. **开始录音**：点击麦克风按钮（单击）
2. **持续录音**：松开手指，继续录音
3. **停止录音**：再次点击麦克风按钮

### 配置选项

- **配置项**：`micTapToggleEnabled = true`
- **路径**：`设置 → 语音识别设置 → 麦克风点按控制`（开启）

### 特点

::: tip 优势

- ✅ 解放双手，适合长时间录音
- ✅ 可边录音边查看其他内容
- ✅ 录音过程中手指无压力
- ✅ 适合口述长文本
  :::

::: warning 局限

- ⚠️ 需要记得点击停止（可能忘记）
- ⚠️ 误触风险略高
  :::

### 手势增强

点按模式下支持手势控制：

- **向左滑动**：取消本次录音
- **向右滑动**：直接发送识别结果

### 适用场景

- 口述长文本（如文章、报告）
- 会议记录
- 需要边录音边操作其他内容
- 与智能判停（VAD）配合使用

## 与其他功能配合

### 通过键盘按钮快速切换

如果经常在短句和长文本之间切换，可以把「录音模式切换」加入键盘布局：

1. 打开 `设置 → 输入设置 → 自定义键盘布局`
2. 选择一个扩展按钮或键盘按钮位置
3. 将动作设置为「录音模式切换」
4. 回到键盘后，点击该按钮即可在长按说话与点按切换之间切换

### 搭配智能判停（VAD）

点按切换模式 + 智能判停 = 接近连续对话体验：

```
设置 → 语音识别设置 → 麦克风点按控制：开启
设置 → 语音识别设置 → 智能静音判停：开启
```

效果：点击开始后自动检测静音停止，接近 Pro 连续对话模式
