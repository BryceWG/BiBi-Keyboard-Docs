# 配置备份

说点啥支持完整的配置备份和恢复功能，包括文件备份、WebDAV 同步，以及 Pro 版自动备份。

备份入口：`设置 → 系统 → 配置备份`。

## 文件备份

文件备份可将所有设置导出为 JSON 文件，手动保存和恢复。

### 导出到文件

在 `设置 → 系统 → 配置备份 → 文件备份` 中点击「导出到文件」，将当前配置导出为 JSON 文件。

::: info 版本标识
导出的 JSON 包含 `_version` 字段（当前为 `1`），用于未来版本兼容。
:::

::: warning 敏感信息
导出文件包含所有 API Key、密码等敏感信息，请妥善保管，不要分享给他人或上传到公开位置。
:::

### 从文件导入

在 `设置 → 系统 → 配置备份 → 文件备份` 中点击「从文件导入」，从 JSON 文件恢复配置。

::: tip 选择性恢复
备份 JSON 可手动编辑：如果只想恢复部分配置，可以在导入前删除不需要恢复的字段。手动编辑需谨慎，格式错误可能导致导入失败。
:::

## WebDAV 同步

WebDAV 同步可将配置保存在 WebDAV 服务器上，便于跨设备恢复。该功能开源版即可使用。

### 配置 WebDAV

在 `设置 → 系统 → 配置备份 → WebDAV 同步` 中填写服务器信息：

| 配置项 | 说明 |
|--------|------|
| 服务器地址 | WebDAV 服务器 URL（如 `https://dav.example.com`） |
| 用户名 | WebDAV 用户名（可选） |
| 密码 | WebDAV 密码（可选） |

### 上传 / 恢复

- **上传**：将当前配置上传到 WebDAV 服务器
- **恢复**：从 WebDAV 服务器下载配置并应用

## 自动备份（Pro）<Badge type="warning" text="Pro" />

Pro 版支持定时自动备份，按设定的间隔自动将配置上传到 WebDAV。

1. 进入 `设置 → 系统 → 配置备份 → 自动备份（Pro）`
2. 开启「启用自动备份」并填写 WebDAV 服务器信息
3. 设置备份间隔：由「间隔数值 + 单位（小时/天）」组成，最小 6 小时
4. 页面会显示「下次预计备份时间」与「上次备份」状态

::: info 说明
WebDAV 备份内容与手动备份一致，仅会在云端存储一份配置文件。
:::

## 故障排查

### 导入失败

**可能原因**：

1. JSON 格式错误：文件损坏或编辑错误
2. 版本不兼容：来自未来版本的备份文件
3. 配置值超出范围：手动编辑时输入了非法值

**解决方法**：

- 使用 JSON 验证工具检查格式
- 确保文件完整未损坏
- 不要手动修改不熟悉的字段

### WebDAV 备份失败

**可能原因**：
- 检查网络连接和 WebDAV 配置
- 在浏览器中测试 WebDAV 连接
- 清理服务器上的旧备份文件
- 查看错误提示信息

## 附录：备份文件结构

::: info 备份文件结构
备份文件是标准 JSON 格式，可读性好，支持手动编辑（需谨慎）。

示例片段：

```json
{
  "_version": 1,
  "app_language_tag": "zh-Hans",
  "keyboard_height_tier": 2,
  "asr_vendor": "siliconflow",
  "sf_free_asr_enabled": true,
  "trim_final_trailing_punct": true
}
```

历史相关键名：

- `asr_history`：识别历史记录（JSON 数组，未禁用历史记录功能时包含在备份中）
- `clip_pinned`：固定的剪贴板记录（非固定的剪贴板记录不会导出）
:::

::: warning 隐私提示
识别历史包含识别的文本内容。如果担心隐私泄露：

1. 在 `设置 → 其他设置 → 记录留痕` 中开启「关闭识别历史记录」
2. 在备份前手动清除历史记录
3. 或在导出后手动编辑 JSON 文件删除 `asr_history` 字段
:::
