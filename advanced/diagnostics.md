# 识别历史与诊断

本页介绍如何查看识别历史、API Log 和录音测试页面，帮助你排查供应商配置、网络请求、模型加载和录音质量问题。

## 识别历史

识别历史用于回看每次语音输入的结果与基础统计信息。

### 查看入口

1. 打开说点啥设置
2. 在设置首页进入「识别历史」
3. 按来源、时间或内容查看记录

也可以在键盘内快速查看：在自定义键盘布局中添加「识别历史」扩展按键后，点击即可打开历史面板，点击条目插入文本，左右滑动可重新识别或重新润色。

### 可查看的信息

- **来源**：键盘输入、悬浮球输入、外部输入等
- **供应商**：本次识别使用的 ASR 引擎
- **识别文本**：最终提交前后的文本结果
- **耗时信息**：总耗时、识别耗时、AI 后处理耗时（旧记录可能缺少部分字段）

### 阶段时间轴

新版记录的历史详情提供「阶段时间轴」，按阶段展示耗时分布，便于判断慢在哪个环节：

- **录音 / 音频输入**：采集语音的阶段耗时
- **语音识别**：ASR 引擎返回结果的耗时
- **后处理**：本地文本过滤、正则等后处理阶段
- **AI 润色**：LLM 润色阶段（开启并尝试时）
- **文字写入**：结果提交到输入框的耗时

旧版本创建的记录会显示「此记录由旧版本创建，未保存阶段耗时」。

### 失败记录

识别失败、超时或取消的记录也会被保留，并展示失败原因（如鉴权失败、麦克风被占用、网络不可用、识别超时等）。保留录音的记录可以通过重新识别重试。

## API Log

API Log 记录最近的 ASR / LLM 调用摘要，适合用来判断是密钥、端点、模型、网络还是供应商返回错误导致识别失败。

### 查看入口

1. 打开 `设置首页 → 识别历史`
2. 点击页面右上角的 `API Log` 图标按钮
3. 使用顶部筛选查看 ASR、LLM 或失败记录

### 记录内容

API Log 会记录：

- 供应商、模型、请求域名与路径
- 请求耗时与成功 / 失败 / 取消状态
- 请求结构摘要、响应摘要或错误信息
- 本地 ASR 的模型加载、推理来源与耗时

::: warning 隐私说明
API Log 只保存本地请求摘要。API Key、录音音频和完整识别文本不会保存到 API Log 中。
:::

### 什么时候查看 API Log

- 新配置 API Key 后测试失败
- 某个供应商突然无法识别
- 想确认当前调用的是哪个模型或端点
- 本地模型首次使用很慢，想确认是否在加载模型
- AI 后处理返回空结果或错误

## 录音测试

录音测试页面用于在不打开键盘的情况下测试当前 ASR 配置，并查看录音与识别链路中的关键状态。

### 使用方法

1. 打开 `设置首页 → 录音测试`
2. 选择或确认当前 ASR 配置
3. 点击录音按钮开始测试
4. 查看识别结果、错误提示、耗时与音频分析信息

### 推荐使用场景

- 首次配置新供应商后，先在录音测试页确认可用
- 切换本地模型后，确认模型已下载并能正常加载
- 调整录音判停、自动过滤静音部分或上传音频前压缩后，对比识别结果
- 给他人反馈问题前，先截取错误提示或 API Log 摘要

## 使用统计

在设置首页进入「使用统计」，可以查看：

- 总音频时长、总识别字数、会话次数与平均输入速度
- 最近 7 天使用量，以及近 7 天/4 周平均值
- 各 ASR 供应商的使用量与近 30 天在线 ASR 失败率

点击右上角的分享按钮可以预览使用记录卡片，再将图片保存到 `Pictures/BiBi` 或通过系统分享。卡片会跟随当前界面主题生成。

如不希望本地记录这些汇总数据，可在 `设置 → 其他设置` 开启「关闭数据统计记录」。开启后会清除已有统计并停止记录新数据。

## 清理记录

你可以在历史页或 API Log 页的菜单中清空对应记录。清空只影响本机保存的历史与摘要，不会删除供应商控制台中的用量记录。
