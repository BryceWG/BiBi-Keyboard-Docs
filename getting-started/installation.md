# 安装指南

本页介绍如何下载和安装说点啥（BiBi Keyboard）。

## 系统要求

在安装之前，请确保您的设备满足以下要求：

| 项目             | 要求                          |
| ---------------- | ----------------------------- |
| **Android 版本** | Android 10 (API 29) 及以上    |
| **CPU 架构**     | arm64-v8a（仅支持 64 位设备） |
| **存储空间**     | 至少 50 MB 可用空间           |
| **网络**         | 云端 ASR 需要网络连接         |

::: info 关于 CPU 架构
说点啥仅提供 arm64-v8a 版本，不支持 32 位设备（armeabi-v7a）和 x86 架构。大部分 2018 年后发布的设备都支持 64 位架构。
:::

## 下载渠道

### GitHub Releases（推荐，开源版）

从 GitHub Releases 页面下载开源版 APK：

1. 访问 [Releases 页面](https://github.com/BryceWG/BiBi-Keyboard/releases)
2. 找到最新的 Release 条目
3. 在附件列表中下载标记为开源版的 APK 文件（包名为 `com.brycewg.asrkb`）

::: tip 开源版说明

- 开源版包含所有核心语音识别功能，适合大多数用户
- Pro 版为独立付费应用（包名 `com.brycewg.asrkb.pro`），仅通过 Google Play 商店分发，不提供单独 APK 下载
  :::

### Google Play 商店（Pro 版）

如果你需要 Pro 功能（如连续说话模式等），可以在 Google Play 商店搜索 **"BiBi Keyboard Pro"** 或 **"说点啥 Pro"**，或进入[软件页面](https://play.google.com/store/apps/details?id=com.brycewg.asrkb.pro)并购买下载。Pro 版应用仅通过 Google Play 商店提供，不提供单独 APK 文件。
也可以在开源版关于页面找到 Pro 版更多相关内容和购买方案。

## 安装步骤

### 1. 下载 APK 文件

根据您的需求选择开源版，并将 APK 安装到您的 Android 设备。

### 2. 安装 APK

1. 打开文件管理器，找到下载的 APK 文件
2. 点击 APK 文件，系统会弹出安装提示
3. 点击「安装」按钮
4. 等待安装完成，点击「完成」

## 启用输入法

安装完成后，需要将说点啥设置为系统输入法：

### 1. 启用输入法

1. 打开「设置」→「系统」→「语言和输入法」
2. 选中「说点啥」或「BiBi Keyboard」

### 2. 切换到说点啥

1. 在语音和键盘管理页面中点击当前输入法
2. 选择「说点啥」或「BiBi Keyboard」

### 3. 供应商一键配置

说点啥提供一键配置功能，帮助您快速完成首次语音识别配置：

1. 打开说点啥应用
2. 启动时弹出基础使用教程
3. 说点啥提供三种推荐配置方案：
   - 一键使用硅基流动免费服务（推荐新用户）
   - 配置云端供应商，即自行配置 API Key
   - 配置本地模型，自动下载并使用本地离线模型-Sensevoice small
4. 选择合适方案并按照提示完成配置

## 授予必要权限

首次使用时，说点啥需要以下权限：

| 权限                                                     | 用途               | 必需性         |
| -------------------------------------------------------- | ------------------ | -------------- |
| **录音（RECORD_AUDIO）**                                 | 采集语音进行识别   | 必需           |
| **网络访问（INTERNET）**                                 | 调用云端 ASR 服务  | 云端 ASR 必需  |
| **省电优化忽略（REQUEST_IGNORE_BATTERY_OPTIMIZATIONS）** | 保持后台服务运行   | 推荐           |
| **悬浮窗（SYSTEM_ALERT_WINDOW）**                        | 显示悬浮球         | 使用悬浮球必需 |
| **无障碍服务（BIND_ACCESSIBILITY_SERVICE）**             | 支持悬浮球语音输入 | 使用悬浮球必需 |
| **通知（POST_NOTIFICATIONS）**                           | 显示通知           | 可选           |
| **安装未知应用（REQUEST_INSTALL_PACKAGES）**             | 安装更新 APK       | 可选           |

首页上方一键设置功能可帮助快速完成重要权限配置。

## 验证安装

安装完成后，您可以验证是否安装成功：

1. 打开任意应用的输入框
2. 确认当前输入法已切换为说点啥
3. 您应该能看到说点啥的界面，包括麦克风按钮

如果一切正常，您可以继续进行其他配置[首次设置](/getting-started/first-setup)。

## 常见问题

### 安装失败

**问题**：安装时提示"应用未安装"或"解析软件包时出现问题"

**解决方案**：

1. 确认您的设备支持 arm64-v8a 架构
2. 检查存储空间是否充足

### 权限请求未弹出

**问题**：首次使用时未弹出权限请求

**解决方案**：

1. 手动进入「设置」→「应用」→「说点啥」→「权限」
2. 手动授予麦克风、悬浮窗等必要权限
