# 隐私声明

**最后更新：2026-02-23**

## 简介

说点啥（BiBi Keyboard，以下简称“本应用”）致力于保护用户隐私。本页面说明应用在不同功能下会处理哪些数据。

## 核心原则

- 本应用不会把你的语音录音、识别文本内容上传到“我们自有服务器”进行存储或分析。
- 本应用主要作为客户端工作：你配置了哪些第三方 ASR/LLM 服务，数据才会直连到对应服务商。

## 匿名数据采集（可选，默认关闭）

应用内存在“匿名使用数据采集”开关（`设置 -> 其他设置`）。仅在你开启后，才会进行匿名统计上报。

### 1. 每日匿名统计上报（开启后）

上报内容包含：

- 匿名用户标识（随机 UUID）
- 应用版本号
- 应用语言
- 上报时间戳
- 每日随机上报时段（分钟）
- 当日聚合统计：ASR 事件数、音频总时长、应用启动次数
- ASR 事件元数据列表（不含文本内容）：
  - 事件时间戳
  - 识别供应商 ID（`vendorId`）
  - 音频时长（`audioMs`）
  - 处理耗时（`procMs`）
  - 来源（`ime` / `floating` / `external`）
  - 是否使用 AI 后处理（`aiProcessed`）
  - 字符数统计（`charCount`）

### 2. 同意状态上报（你选择同意/拒绝或切换开关时）

应用会更新一条匿名同意记录，字段包括：

- 匿名用户标识（随机 UUID）
- 是否启用匿名采集（`enabled`）
- 安装来源渠道（安装器包名）
- 首次使用时间（`firstSeen`）
- Android SDK 版本
- 设备型号（厂商 + 型号）
- 应用版本号
- 应用语言
- 记录时间戳

## 我们明确不采集的内容

- 语音录音原始音频
- 语音识别文本正文
- 键盘输入正文
- 姓名、手机号、邮箱等账号身份信息

## 本地存储数据

以下数据默认保存在你的设备本地：

- 应用配置（包括 API Key 等）
- 识别历史（可关闭）
- 使用统计（可关闭）
- 语音预设
- 匿名统计待上报缓存（仅在你开启匿名采集后）

## 第三方服务说明

当你使用云端功能时，数据会直接发送到你配置的第三方服务：

- ASR 服务（如火山引擎、OpenAI、Gemini、Soniox、百炼等）
- LLM 后处理服务（你配置的 OpenAI 兼容服务）

这些第三方服务有各自的隐私政策与数据处理规则，请以其官方说明为准。

## 其他可选云功能

- 剪贴板同步：仅在你启用并配置后生效
- WebDAV 备份：仅在你启用并配置后生效

## 你的控制权

你可以随时：

- 关闭“匿名使用数据采集”
- 关闭识别历史
- 关闭使用统计
- 卸载应用并删除本地数据
