# Pro 功能介绍

说点啥 Pro 版在开源版的基础上，提供了更多专业功能和增强特性，满足高级用户的需求。

## 功能概览

Pro 版包含以下独有功能:

- **离线繁体转换**: 自动将识别结果转换为繁体中文
- **热词管理**: 多供应商统一热词注入，提升专有名词识别准确率
- **应用专属 Prompt**: 按前台应用自动切换 AI 后处理 Prompt
- **畅说模式**: VAD 自动开始/停止录音，无需手动控制
- **全向光标滑动**: 增强的光标控制，支持四向滑动
- **WebDAV 自动备份**: 设置云端自动备份，多设备同步
- **正则后处理**: 使用正则表达式进行文本后处理
- **个性化 UI 取色**: 更丰富的颜色自定义选项

## 离线繁体转换 <Badge type="warning" text="Pro" />

自动将简体中文识别结果转换为繁体中文，适合繁体中文用户使用。

### 功能特点

- **智能转换**: 使用先进的离线简繁转换算法
- **无缝集成**: 转换自动进行，不影响识别速度
- **全局生效**: 支持所有 ASR 供应商和输入场景

### 使用方法

1. 打开说点啥 Pro 设置
2. 进入 `设置 → 输入设置 → Pro 功能 → 识别结束后转换为繁体`
3. 可选转换规则:
   - **标准转换**: 常规简繁转换
   - **台湾用语**: 适合台湾地区的用词习惯
   - **香港用语**: 适合香港地区的用词习惯

::: tip 提示
繁体转换会在所有文本处理（包括 AI 后处理）完成后应用，确保最终结果为繁体中文。
:::

## 热词管理 <Badge type="warning" text="Pro" />

管理自定义热词，提升专有名词、品牌名、人名等特殊词汇的识别准确率。

### 功能特点

- **多供应商支持**: 自动适配不同 ASR 供应商（本地模型、Elevenlabs 不支持）的热词格式
- **可注入到后处理 Prompt**: 可以一键注入热词到指定的 AI 后处理 Prompt 中
- **统一适配**: 自动适配不同供应商的热词要求和格式，对于不直接支持热词的供应商，将内容结构化注入到识别 Prompt 参数中

### 使用方法

1. 打开说点啥 Pro 设置
2. 进入 `设置 → 语音识别设置 → 识别结果优化（Pro）`
3. 在热词区域添加/导入热词（支持从剪贴板批量导入）
4. 保存后自动应用

> 热词数量不宜过多（根据不同供应商说明），过多会影响识别性能

### 新增能力（更易用）

- **一键清空 + 撤销**：支持批量清空热词，并可在提示条中点击“撤销”恢复
- **选词菜单快速添加**：在任意应用选中文本，选择「添加热词到「说点啥」」即可一键加入热词列表

### 支持热词的供应商

| 供应商      | 支持状态 | 最大数量                                    |
| ----------- | -------- | ------------------------------------------- |
| Volcengine  | ✅       | 100 tokens(双向流式) / 5000 个              |
| DashScope   | ✅       | 10000 tokens                                |
| Soniox      | ✅       | 8000 tokens                                 |
| SiliconFlow | ✅       | 几乎无限（Sensevoice 和 Telespeech 不支持） |
| OpenAI      | ✅       | 取决于模型                                  |
| Gemini      | ✅       | 几乎无限                                    |
| GLM ASR     | ✅       | 100 个                                      |
| ElevenLabs  | ❌       | -                                           |
| 本地模型    | ❌       | -                                           |

## 畅说模式 <Badge type="warning" text="Pro" />

基于 VAD（Voice Activity Detection）的自动录音模式，检测到语音自动开始，检测到静音自动停止。

### 功能特点

- **自动开始**: 点击麦克风后，检测到语音自动开始录音
- **自动停止**: 检测到静音后自动结束录音并识别
- **连续对话**: 支持连续多次识别，无需反复点击
- **智能检测**: 可配置静音时长和敏感度

### 使用方法

1. 打开说点啥 Pro 键盘面板
2. 键盘面板上点击畅说模式开关（需要在设置-输入设置-扩展按钮配置中添加畅说模式按钮）
3. 通过按钮激活畅说模式，开始说话
4. 配置 VAD 参数:
   - **静音时长**: 0.5-3 秒（默认 1.5 秒）
   - **检测灵敏度**: 1-10（默认 5）

::: warning 注意

- 畅说模式需要麦克风始终处于监听状态，会增加电池消耗
- 在极其嘈杂的环境中可能误触发，建议切换回长按模式
- 启用畅说模式时可能需要一两个词的时间才能触发开始录音
  :::

## 全向光标滑动 <Badge type="warning" text="Pro" />

在空格键上实现全向滑动控制

### 使用方法

1. 开启 `设置 → 输入设置 → Pro 功能 → 光标滑动模式`
2. 在键盘面板上，才空格位置开始上滑触发光标滑动功能
3. 麦克风按钮会变成四个方向的箭头图标，表示可以滑动
4. 从光标当前位置，向上/下/左/右滑动以移动光标，输入框中的光标会跟随手指位置移动而相应移动

## WebDAV 自动备份 <Badge type="warning" text="Pro" />

自动备份说点啥的所有设置到 WebDAV 云端存储，支持多设备同步。

### 功能特点

- **自动备份**: 定时备份
- **多设备同步**: 在其他设备登录相同账号即可恢复设置

### 使用方法

1. 打开说点啥 Pro 设置
2. 进入 `设置 → 配置备份`
3. 开启 `开启自动备份`
4. 填入 WebDAV 服务器信息:
   - **服务器地址**: 如 `https://dav.example.com`
   - **用户名**: WebDAV 账号
   - **密码**: WebDAV 密码
   - **备份时间间隔**: 可以选择时间单位和数值
5. 可以观察备份状态和上次备份时间

::: info 说明
WebDAV 备份内容与手动备份一致。
仅会在云端存储一份配置文件。
:::

## 正则后处理 <Badge type="warning" text="Pro" />

使用正则表达式对识别结果进行自定义文本处理，实现复杂的文本转换需求。

### 功能特点

- **正则匹配**: 支持完整的 Java 正则表达式语法
- **多规则链**: 按顺序应用多个正则规则
- **规则模板**: 一键添加常用模板，并自动补全规则备注
- **规则备注**: 备注仅用于列表展示，不影响匹配与替换逻辑

### 使用方法

1. 打开说点啥设置
2. 进入 `设置 → 语音识别设置 → 识别结果优化（Pro）`
3. 开启功能开关，点击 `新建规则`（或使用 `常用模板` 一键添加）
4. 填写规则信息:
   - **匹配正则**: 正则表达式
   - **替换内容**: 替换文本（支持 `$1`、`$2` 等捕获组）
   - **匹配选项**: 忽略大小写、多行模式等
   - **备注（列表显示）**: 给规则起个名字，方便管理（不影响规则效果）
5. 点击保存，规则会按顺序应用

::: tip 提示
正则后处理在 AI 后处理之后应用，可以用来规范 AI 输出的格式。
:::

## 应用专属 Prompt <Badge type="warning" text="Pro" />

> 此功能仅在 Pro 版中可用

为不同应用配置不同的 AI 后处理 Prompt：例如在聊天软件用“通用后处理”，在笔记软件用“基础润色”，在任务工具用“提取待办事项”。

### 使用方法

1. 打开 `设置 → AI 后处理`
2. 点击「应用专属 Prompt（Pro）」进入配置页
3. 开启「启用应用专属 Prompt」
4. 点击「添加应用」，选择目标应用并为其指定 Prompt

::: warning 注意
该功能需要开启说点啥的无障碍服务，用于识别“当前前台应用”以自动选择 Prompt；不会读取聊天内容等屏幕文本。
:::

## 个性化 UI 取色 <Badge type="warning" text="Pro" />

在开源版 Material3 动态取色的基础上，提供更丰富的颜色自定义选项。

### 功能扩展

开源版支持:

- Material3 动态颜色主题

Pro 版额外支持:

- **内置多种主题色**: 不受系统壁纸限制，自由选择主题色

### 使用方法

1. 打开说点啥设置
2. 进入 `设置 → 其他设置 → 自定义配色`
3. 根据需要配置:
   - **主题色**: 选择自定义颜色

::: info 说明
自定义配色会覆盖 Material3 动态颜色，选择自定义配色中第一个选项可恢复默认行为。
:::
